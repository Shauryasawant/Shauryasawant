## Currently Working On

**DAGC — Decision-Anchored Graph Compression**
A context-compression framework for LLM agent traces that prioritizes preserving decision-critical information over pure semantic similarity. It introduces the Decision Reproducibility Rate (DRR), a metric for measuring whether compressed traces preserve an agent's original decisions and reasoning outcomes.

- ~73% context compression while maintaining 0.82–0.90 DRR and 1.0 reasoning-chain integrity
- Outperformed 12 competitive compression baselines across the evaluation benchmark
- Adversarial robustness testing: noise injection, contradiction attacks, decision masking
- Published as a citable research artifact via Zenodo: [10.5281/zenodo.21621103](https://doi.org/10.5281/zenodo.21621103)
- Repo: [DAGC-Decision-Anchored-Graph-Compression](https://github.com/Shauryasawant/DAGC-Decision-Anchored-Graph-Compression)
